## About

I work at the intersection of Machine Learning, Generative AI and Agentic AI, building systems that go beyond single model calls into reasoning, retrieval and multi agent workflows. My work spans translation platforms, retrieval augmented generation pipelines, computer vision systems and multi agent orchestration, with a consistent focus on solutions that are practical, scalable and grounded in real engineering rather than novelty for its own sake.

Most of what I build starts from a simple question, does this actually hold up outside a notebook. That question has led to projects comparing retrieval architectures, building secure multi agent systems, and applying deep learning to real detection and classification problems in production style settings.
